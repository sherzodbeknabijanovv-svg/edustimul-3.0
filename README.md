## 🛠️ Featured Project: EduStimul 3.0
A full-stack, distraction-free learning ecosystem engineered for students preparing for high-stakes exams (IELTS, SAT, and beyond). 

### 💡 Core Concept & Features
- **Environment, Not Content:** EduStimul doesn't tell students what to learn; it provides the ultimate environment to master any subject efficiently.
- **Context-Rich Smart Flashcards:** Custom word sets and study flashcards that answer three essential questions: *What to remember? Why it matters? When to use it?*
- **Background Pomodoro Timer:** A focus timer that runs without locking your screen, allowing students to study across external resources and alerting them when time's up.
- **Daily Wishlist:** A micro-goal planner where students log morning objectives, track time-based reminders, and check off completed tasks.
- **Interactive Quiz Engine:** Built-in dynamic 10-question evaluation tools and optional Cambridge/College Board-inspired exam simulators.

### 🏗️ Tech Stack
- **Frontend:** Next.js (TypeScript), React, Tailwind CSS
- **Backend:** FastAPI (Python 3.10+), REST & WebSockets
- **Database:** PostgreSQL with SQLAlchemy ORM
- **Deployment:** Render & Vercel
